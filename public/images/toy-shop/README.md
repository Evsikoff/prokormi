# Иллюстрации магазина игрушек

Созданы встроенным генератором изображений (ImageGen), затем проверены на экране магазина. Общий запрос для серии: «Тёплый сказочный магазин игрушек для детской игры; рисованная 2D-иллюстрация, мягкие солнечные цвета, бирюзовый, охра и лиловый, заметная фактура кисти, округлые формы, без букв, цифр, логотипов и интерфейса; единый ракурс и свет». Текст и интерактивные элементы наложены средствами HTML/CSS.

Ростомер, стенды, баннер, бирки, тележка и движущаяся ручка автомата построены в CSS, чтобы подписи и состояния оставались читаемыми и интерактивными. Монстрик использует существующую 3D-модель игрока.

Одиннадцать новых игрушек записаны в ДатаМарт строками 421–431 с `day_is_it_available: 11` и `mood_change: 5`; три дополнительные полки появляются после десятого игрового дня. Настроение теперь сохраняет все заработанные очки выше прежнего предела +3.

Ещё пятнадцать игрушек записаны строками 432–446 с такими же условиями появления и бонусом настроения +5. Их иллюстрации сохранены в WebP с прозрачностью, чтобы уменьшить загрузку новых полок.
