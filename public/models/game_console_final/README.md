# Финал с игровой приставкой: модели для сборки сцены

Эскизы двух кадров и отдельные изображения предметов лежат в
`../../images/game_console_final/concept/`. Кадр `scene-play.png` показывает игру
вечером дома; `scene-thanks.png` — момент, когда питомец откладывает контроллеры,
поворачивается к игроку и благодарит его. Вертикальные варианты для игрового
экрана 9:16 — `scene-play-portrait.png` и `scene-thanks-portrait.png`.
Голубой монстрик на эскизах служит
только примером: в сцене нужно использовать **текущую модель питомца игрока**
`/model/monster.glb` с сохранёнными настройками меха, ушей и рожек из редактора.
Отдельный GLB монстрика здесь не нужен.

## Модели приставки

Три готовых `.glb` лежат **в этой папке** с точными именами:

| Имя файла | Референс | Что должно быть в модели | Ориентир размера (Ш × В × Г) |
| --- | --- | --- | --- |
| `game-console.glb` | `game-console.png` | Фиолетово-синий корпус купленной приставки, встроенный экран, кнопки, пустые боковые крепления для снятых контроллеров | 0,46 × 0,37 × 0,36 м после масштабирования |
| `controller-left.glb` | `controller-left.png` | Съёмный зелёный левый контроллер с крестовиной | 0,10 × 0,22 × 0,055 м |
| `controller-right.glb` | `controller-right.png` | Съёмный оранжевый правый контроллер с кнопками и стиками | 0,10 × 0,22 × 0,055 м |

Референсы в таблице находятся в `../../images/game_console_final/concept/`.
Приставка стоит на пуфе; контроллеры сначала в лапах монстрика, затем лежат на
ковре. Экран должен позволять заменить изображение игры без переделки корпуса.
Окно со шторами теперь создаётся процедурно в `game-console-window.js`; файл
`night-window.glb` больше не требуется. Референс `night-window.png` оставлен как
ориентир для внешнего вида.

## Объекты комнаты, которые уже готовы

Их повторно моделировать не нужно. Для удобства отдельные изображения этих
предметов также скопированы в папку концептов под теми же базовыми именами.

| Предмет | Готовая модель |
| --- | --- |
| Коврик-лапка | `/room/models/paw-rug.glb` |
| Мягкий пуф под приставкой | `/room/models/stool.glb` |
| Лежанка | `/room/models/nest-bed.glb` |
| Светильник-облако | `/room/models/cloud-lamp.glb` |
| Скамья с ящиками | `/room/models/storage-bench.glb` |
| Шкаф | `/room/models/wardrobe.glb` |
| Лазалка | `/room/models/climbing-tower.glb` |

Стол справа, пол, стены, потолок и мелкий декор уже собираются в `room.js`.
Вечернее освещение задаётся в сцене кодом: тёплый свет облака, слабый холодный
свет окна и мягкий свет экрана. При сборке композицию можно упростить по сравнению
с эскизом, сохранив эти основные предметы.

## Подготовка GLB

- Единицы — метры; `Y` направлена вверх, лицевая сторона экрана и окна — к `+Z`.
- Приставка и контроллеры масштабируются при загрузке: в приложенных файлах
  корпус значительно крупнее игрового размера, а контроллеры меньше.
- Не объединяйте контроллеры с корпусом. Проверьте, что их можно пристыковать к
  бокам корпуса и без изменения геометрии положить на ковёр.
- У приложенной приставки экран не выделен отдельным узлом; игровая картинка
  накладывается поверх него отдельной плоскостью в сцене.

После покупки цели `id: 96` игра сначала показывает монстрика за игрой,
затем кадр благодарности. Текст берётся из строки ДатаМарта `Monster line`,
`id: 456`, `trigger: game-console-thanks`; для озвучки указан файл
`public/audio/game_console_final/game_console_thanks.mp3`.
Сцену можно пересмотреть из комнаты так же, как «Праздник огней».
