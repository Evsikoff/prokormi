# Праздник огней: модели для будущей 3D-сцены

Складывайте сюда модели в формате `.glb`. Все референсы лежат в `../../images/festival_lights/concept/`.

| Файл модели | Референс | Назначение |
| --- | --- | --- |
| `dance-platform.glb` | `dance-platform.png` | круглая площадка, центр сцены |
| `lantern-arch.glb` | `lantern-arch.png` | арка над дальним краем площадки |
| `guest-cream.glb` | `guest-cream.png` | танцующий гость слева |
| `guest-green.glb` | `guest-green.png` | танцующий гость справа |
| `guest-orange.glb` | `guest-orange.png` | танцующий гость спереди |
| `paper-lantern.glb` | `paper-lantern.png` | повторяемый подвесной фонарь |
| `flower-planter.glb` | `flower-planter.png` | две клумбы по краям площадки |

Питомца игрока отдельным `.glb` не создавайте: в сцену нужно подставить текущую модель и настройки внешности из редактора. Фиолетовый силуэт на эскизах обозначает только его место в кадре. Деревья, дорожку и небо можно взять из существующей сцены парка.

Для каждого `.glb`: единицы измерения — метры, ось `Y` вверх, модель стоит на плоскости `Y = 0`, начало координат по центру основания. У гостей нужны отдельные узлы рук и ног для анимации танца; имена узлов согласуем при сборке сцены. Фонари должны иметь отдельный материал светящейся части.

После танца гости уходят в глубину, камера приближается к питомцу. Его благодарность хранится в строке ДатаМарта `Monster line` с триггером `festival-lights-thanks`; озвучка находится в `public/audio/festival_lights/festival_lights_thanks.mp3`. Музыка `Saturday_Morning_High_Score.mp3` лежит в корне `finalapp` и включается при входе на праздник.
