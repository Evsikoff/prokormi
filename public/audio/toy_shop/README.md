# Озвучка магазина игрушек

Строки 324–348 в `monster_data_mart_rows.json` — источник текстов, порядка, триггеров и путей к озвучке. Указанные WAV-файлы пока отсутствуют: положите свои записи по этим путям, и приложение начнёт их воспроизводить. Тексты уже показываются без звуковых файлов.

Музыка `Moonbeam_Toyshop.wav` лежит в корне проекта. В `public/audio/toy_shop/` находятся готовые эффекты `coin.wav`, `crank.wav`, `drop.wav`, `open.wav`, `duplicate.wav`, `beep.wav`, `belt.wav`, `robot_jingle.wav`; их создаёт `scripts/make-toy-audio.py`.
