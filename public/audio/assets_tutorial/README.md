# Озвучка туториала «Активы и пассивы»

Положите сюда пять файлов с голосом туториальщицы (строки 268–272 DataMart):

- `assets_tutorial1.wav` — карточка с вещью;
- `assets_tutorial2.wav` — корзины «Актив» и «Пассив», как положить вещь;
- `assets_tutorial3.wav` — виртуальный капитал и счётчик разобранных вещей;
- `assets_tutorial4.wav` — кнопка «Правила», ошибочная вещь возвращается в стопку;
- `assets_tutorial5.wav` — выход в комнату, награда только за всю стопку.
