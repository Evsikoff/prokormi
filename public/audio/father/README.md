# Озвучка папы

Положите в эту папку два файла, указанных в DataMart:

- `father_tennis_01_angry.mp3` — сердитая реплика о разбитом фонаре;
- `father_tennis_02_offer.mp3` — воодушевлённая реплика с предложением оплатить 90% сметы.

Для эпизода «Аккредитивы» (строки 141–143):

- `father_loc_01_alarmed.wav` — встревоженная реплика о LLM, начитавшейся «Незнайки в Солнечном городе»;
- `father_loc_02_request.wav` — просьба подменить сотрудника, который составляет аккредитивы;
- `father_loc_03_thanks.wav` — благодарность и 50 монет в копилку.

Для эпизода «Кредиты для бизнеса» (строки 274–276):

- `father_loans_01_alarmed.wav` — работал не в ресурсе и сломал систему выдачи кредитов;
- `father_loans_02_request.wav` — в банке тысячи людей, поэтому правил он не знает: просьба посидеть за его столом;
- `father_loans_03_thanks.wav` — «достоин всей моей зарплаты» и 60 монет в карман.
