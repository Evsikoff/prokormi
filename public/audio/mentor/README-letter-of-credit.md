# Реплики ментора для эпизода с аккредитивами

Положите в эту папку семнадцать файлов (строки 180–196 DataMart):

- `mr9-1.wav`, `mr9-2.wav` — объяснение, что такое аккредитив, триггеры и транзакции;
- `mr9-3.wav` … `mr9-7.wav` — клиент «Тыквы для кафе»: лишние карточки, не хватает карточек, неверные этапы, неверная связка, аккредитив принят;
- `mr9-8.wav` … `mr9-12.wav` — клиент «Велосипед с доставкой», в том же порядке;
- `mr9-13.wav` … `mr9-17.wav` — клиент «Новая крыша для школы», в том же порядке.
