# Реплики ментора: итоги второго бюджета (дни 4–6)

Ментор показывает только те реплики, которые подходят к бюджету игрока, в этом порядке.
Последняя реплика звучит всегда. Положите в эту папку семь файлов:

- `mr11-1.wav` — внеплановые доходы: благодарность папы, награды за дополнительные задания (строка 250);
- `mr11-2.wav` — перерасход по статье (строка 251);
- `mr11-3.wav` — по статье потрачено меньше плана (строка 252);
- `mr11-4.wav` — монеты брали из копилки (строка 253);
- `mr11-5.wav` — траты совпали с планом (строка 254);
- `mr11-6.wav` — монстрик закончил шестой день голодным (строка 255);
- `mr11-7.wav` — третий бюджет игрок составляет сам (строка 256).
