# Реплики ментора: эпизод «Поломка удалителя козявок» (день 9)

Вступление звучит после сдачи ковырялки в ремонт. Реплики о прогнозе — когда игрок жмёт «Дальше»
на экране прогноза. Реплики о расчёте — при неверном ответе в «Считаем вместе с ментором». Реплики
о запаске — при выборе запасной ковырялки. Реплики о поломке — на следующих чистках, когда основная
ковырялка ломается (в каждой пятой чистке). Положите в эту папку двадцать файлов:

- `mr15-1.wav` — гарантия бесплатная, но ремонт 3 дня; сначала посчитаем, сколько копить (строка 391);
- `mr15-2.wav` — копилка не растёт, без обещания победы не будет (строка 392);
- `mr15-3.wav` — обещание больше 50 из бюджета невыполнимо (строка 393);
- `mr15-4.wav` — обещание не больше, чем откладывал раньше (строка 394);
- `mr15-5.wav` — победа больше чем через два месяца, можно пообещать больше (строка 395);
- `mr15-6.wav` — прогноз по прежнему темпу принят (строка 396);
- `mr15-7.wav` — обещание принято (строка 397);
- `mr15-8.wav` — расчёт: посчитал, сколько раз НЕ сломается (строка 398);
- `mr15-9.wav` — расчёт: 20% — это не 20 поломок (строка 399);
- `mr15-10.wav` — расчёт: ломается не каждый раз (строка 400);
- `mr15-11.wav` — расчёт: забыл картриджи (строка 401);
- `mr15-12.wav` — расчёт: забыл сам прибор (строка 402);
- `mr15-13.wav` — расчёт: картридж на каждую чистку, а не на поломку (строка 403);
- `mr15-14.wav` — запаска «Козилетт», когда выгоднее вторая «Норма» (строка 404);
