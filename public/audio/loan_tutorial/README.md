# Туториал эпизода «Кредиты для бизнеса» (день 7)

Шаги туториала — строки 285–290 дата-марта (`object_type: 'Business loan tutorial'`). Туториал
показывается один раз, после вступления ментора. Положите в эту папку шесть файлов:

- `loan_tutorial1.wav` — заявка: кто просит деньги, на что и сколько (строка 285);
- `loan_tutorial2.wav` — решение: отказ, первый транш или вся сумма (строка 286);
- `loan_tutorial3.wav` — план расходов и выбор этапа для первого транша (строка 287);
- `loan_tutorial4.wav` — ставка и отсрочка, ключевая ставка 14% (строка 288);
- `loan_tutorial5.wav` — кнопка «Памятка» (строка 289);
- `loan_tutorial6.wav` — подпись решения (строка 290).
