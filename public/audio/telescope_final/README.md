# Озвучка финальной сцены с телескопом

`telescope_thanks.mp3` — загруженная озвучка реплики монстрика из ДатаМарта,
`Monster line`, `id: 457`, `trigger: telescope-thanks`. Игра включает её на
финальном кадре сцены с телескопом.

Запись в ДатаМарте: `audio_folder = public/audio/telescope_final`,
`audio = telescope_thanks.mp3`.
