# Озвучка брифинга финальной части игры

Положите сюда шесть файлов с голосом брифинга (строки 449–454 DataMart, `Final part briefing`):

- `final_briefing1.wav` — начинается финал: копим на выбранные цели или 1500 монет;
- `final_briefing2.wav` — цели покупаются только из копилки, из кармана в копилку — только в бюджете;
- `final_briefing3.wav` — характеристики ниже нуля становятся нулём;
- `final_briefing4.wav` — кормление и чистка теперь автоматические;
- `final_briefing5.wav` — дни идут сами и останавливаются на важных событиях;
- `final_briefing6.wav` — ни одна характеристика не должна упасть до −3, это поражение.
