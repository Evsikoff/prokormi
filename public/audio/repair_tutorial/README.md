# Туториал эпизода «Поломка удалителя козявок» (день 9)

Шаги туториала — строки 409–417 дата-марта (`object_type: 'Repair episode tutorial'`). Первые пять
шагов (`title: 'Прогноз'`) показываются один раз на экране прогноза, последние четыре
(`title: 'Запаска'`) — один раз на экране выбора запаски. Положите в эту папку девять файлов:

- `repair_tutorial1.wav` — цели накоплений или 1500 монет по умолчанию (строка 409);
- `repair_tutorial2.wav` — история копилки и среднее за бюджет (строка 410);
- `repair_tutorial3.wav` — прогноз: день победы (строка 411);
- `repair_tutorial4.wav` — обещание откладывать больше (строка 412);
- `repair_tutorial5.wav` — кнопка «Дальше» (строка 413);
- `repair_tutorial6.wav` — поломка в 20% чисток, ремонт 3 дня (строка 414);
- `repair_tutorial7.wav` — расчёт вместе с ментором (строка 415);
- `repair_tutorial8.wav` — выбор запаски по цене к победе (строка 416);
- `repair_tutorial9.wav` — покупка из кармана и копилки, потом чистка (строка 417).

Ещё одна озвучка лежит в `public/audio/messages`: `m8.wav` — сообщение «Ковырялка вернулась из
ремонта» (строка 418), оно приходит утром 12-го дня.
