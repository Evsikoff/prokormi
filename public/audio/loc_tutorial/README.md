# Озвучка туториала аккредитивов

Положите сюда шесть файлов с голосом туториальщицы (строки 174–179 DataMart):

- `loc_tutorial1.wav` — заявка клиента;
- `loc_tutorial2.wav` — сколько денег в банке и сколько уже в аккредитиве;
- `loc_tutorial3.wav` — этапы, группа триггеров и группа транзакций, кнопки «Добавить этап» и ↑;
- `loc_tutorial4.wav` — связки «И» и «ИЛИ»;
- `loc_tutorial5.wav` — карточки на вкладках и черновики LLM;
- `loc_tutorial6.wav` — подписание аккредитива.
